# Materiais para Consultores e Investidores

Este diretório contém os materiais complementares ao plano de negócios completo (`../PLANO_DE_NEGOCIOS.md`):

- **`Deck_Investidores.pptx`** — apresentação de 14 slides (problema, solução, mercado, comparativo de capitais, unit economics, projeção financeira, investimento, escalabilidade, riscos e veredito).
- **`Modelo_Financeiro.xlsx`** — modelo financeiro editável: premissas, projeção de 24 meses, unit economics (LTV/CAC/payback/breakeven), investimento inicial e matriz de decisão para escolha da praça-piloto entre capitais. Todas as células de fórmula recalculam automaticamente ao alterar as premissas (em azul/amarelo).
- **`Plano_de_Negocios_Clube_Org.docx`** — versão formatada em Word do plano de negócios completo, pronta para compartilhar ou imprimir.

Todos os números de mercado citam suas fontes (seção 2.5 do plano de negócios). Os parâmetros financeiros são estimativas de dimensionamento inicial — devem ser refinados com dados reais assim que o piloto (Fase 0, seção 13) começar a rodar.
